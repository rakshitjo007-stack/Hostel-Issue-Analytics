# Project Statement

## Project Title
Hostel Issue Management System

## Problem Statement
Hostel students may face maintenance issues such as plumbing, electrical, cleaning, and furniture problems. A simple system is needed to record these issues and allow the administration to manage their status.

## Objectives
- Allow students to register and log in.
- Allow students to report hostel issues.
- Generate a ticket ID for each issue.
- Allow students to view their reported issues.
- Allow administrators to view and update reported issues.
- Store issue information permanently.

## Functional Requirements
1. Student registration and login
2. Admin login
3. Issue reporting
4. Issue categorization and priority selection
5. Viewing reported issues
6. Admin issue management
7. Issue status updates
8. Permanent data storage

## Non-Functional Requirements
1. Usability
2. Reliability
3. Maintainability
4. Error handling

## Major Modules
1. User Management
2. Issue Reporting
3. Issue Management
4. Data Storage
